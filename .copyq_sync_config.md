# CopyQ Guest-Host Sync Configuration

## Setup Overview
This configures CopyQ in the guest Ubuntu VM to sync with the host via shared data directory.

## Guest Configuration

### 1. Create shared data directory
```bash
# Already created: /host_zion/projects/visual_audio/.copyq_shared
```

### 2. Configure CopyQ guest instance
```bash
# Create symbolic link to shared data
rm -rf ~/.local/share/copyq/copyq
ln -s /host_zion/projects/visual_audio/.copyq_shared ~/.local/share/copyq/copyq

# Create configuration directory link
rm -rf ~/.config/copyq
ln -s /host_zion/projects/visual_audio/.copyq_config ~/.config/copyq
```

### 3. Start CopyQ with shared configuration
```bash
copyq &
```

## Host Configuration (to be done on host)

### 1. Start CopyQ with same data directory
```bash
# On host terminal:
mkdir -p /home/jericho/zion/projects/visual_audio/.copyq_shared
mkdir -p /home/jericho/zion/projects/visual_audio/.copyq_config

# Copy default config if needed
cp -r ~/.config/copyq/* /home/jericho/zion/projects/visual_audio/.copyq_config/

# Start with shared config
copyq -c /home/jericho/zion/projects/visual_audio/.copyq_config -d /home/jericho/zion/projects/visual_audio/.copyq_shared
```

## Important Notes

### Filesystem Writeback Considerations
- Guest changes to `/host_zion` are immediately durable on host
- CopyQ data written to shared directory persists across guest reboots
- No writeback delay needed for shared directory access

### Conflict Resolution
- CopyQ does not support concurrent write access well
- Best practice: only one instance should write at a time
- For seamless sync, consider using CopyQ's network features or a script to sync

### Alternative: CopyQ Network Sync
CopyQ has experimental network sync features. For more robust syncing:
1. Set up CopyQ server on one machine
2. Configure client mode on the other
3. Use `copyq config network.enabled true`

## Troubleshooting
If CopyQ fails to start:
- Check directory permissions: `ls -la /host_zion/projects/visual_audio/.copyq_shared`
- Verify symbolic links: `ls -la ~/.local/share/copyq/ && ls -la ~/.config/`
- Check CopyQ logs: `copyq info`

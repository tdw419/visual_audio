## Architectural Benefits

### Before: Monolithic WGSL (2,821 lines)
- **Problem**: Adding `MULH` requires editing 2,821-line file
- **Risk**: One wrong brace breaks 400+ opcodes
- **Maintenance**: Understanding code requires reading entire file
- **Testing**: No easy way to test individual opcodes

### After: DSL-Generated WGSL (300 lines + definitions)
- **Solution**: Adding `MULH` = one Python definition (~10 lines)
- **Safety**: Isolated definitions, easier testing
- **Maintainability**: Clear structure, auto-generated documentation
- **Testing**: Per-opcode test generation possible

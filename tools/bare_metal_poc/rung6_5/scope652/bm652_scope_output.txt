  [OK ] so img2's 2,048 bytes are 4 contiguous 512 B runs, one per data plane, 3,407,872 B apart on the medium -- and a contiguous run inside one plane is ONE symbol in each of many codewords, which is exactly the class Hamming(7,4) over byte symbols repairs
  ---- the converse, and the honest boundary: damage that hits the SAME in-plane offset in two data planes is two symbols in one codeword -- BM602's leg G, mis-fixed and refused. That shape is four bytes 3,407,872 B apart, not a scratch; the medium's own geometry decides which faults are in the story.

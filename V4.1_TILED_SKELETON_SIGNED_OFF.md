## Boundary Map

### Public API (`src/pdb/tiled.rs`)

**Structs:**
- `TileCoord` — (tile_x, tile_y) indexing
- `TileMetadata` — Per-tile metadata (bbox, byte_offset, byte_count)
- `TileGridConfig` — Grid dimensions and tile sizing
- `TiledPdbHeader` — Multi-frame header (magic, version, table metadata, tile map)
- `TiledPdbManager` — Multi-frame I/O manager
- `TiledPdbEncoder` — Multi-frame encoder
- `TiledPdbDecoder` — Multi-frame decoder

**Dependencies:**
- Uses existing `PdbError`, `PdbResult`, `TableMetadata`, `BoundingBox` from `mod.rs`
- Uses existing `PdbEncoder`, `PdbDecoder` for individual frame encoding/decoding
- Uses `HashMap` for tile tracking
- Uses `PathBuf` for tile file paths

### Internal Dependencies

**From `mod.rs`:**
- `BoundingBox` — Tile bounding boxes
- `PdbError`, `PdbResult` — Error handling
- `TableMetadata` — Table metadata compatibility

**From `encoder.rs` / `decoder.rs`:**
- `PdbEncoder` — Encode individual tile frames
- `PdbDecoder` — Decode individual tile frames

## Scope Decisions

**In-scope:**
- Multi-frame tile encoding for large tables (rootfs)
- Tile grid management (4096×4096 tiles configurable)
- Tile-to-frame file mapping (e.g., `rootfs.0.0.pdb.png`)
- JSON header serialization for tile metadata

**Out-of-scope (deferred):**
- GPU querying across tiles (future v4.2)
- Tile-level compression
- Tile-level encryption
- Incremental tile updates (write-once only for now)

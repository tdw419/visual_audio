## Phase 1: Tile Chunking Algorithm

**Goal**: Split large binary data into tile-sized chunks with proper byte accounting.

**Steps**:
1. Calculate tile byte capacity: `tile_size * tile_size * 3` (RGB pixels)
2. For input data `[0..N]`:
   - Split into chunks of `tile_byte_capacity`
   - Last chunk may be partial
3. For each chunk:
   - Calculate `byte_offset` (cumulative sum)
   - Calculate `byte_count` (chunk size)
   - Assign to next tile in grid (row-major: left-to-right, top-to-bottom)
4. Record `TileMetadata` in `TiledPdbHeader.tiles`

**Verification**:
- Write unit test: split 1GB data into 8×8 4096×4096 tiles
- Verify byte offsets sum to total data size
- Verify last tile partial chunk handling

**Output**: `TileGridConfig::split_into_tiles(data: &[u8]) -> Vec<TileMetadata>`

## Phase 2: Per-Tile PDB Encoding

**Goal**: Encode each tile as a standalone PDB1 frame.

**Steps**:
1. For each tile from Phase 1:
   - Create `PdbConfig::new(tile_size, tile_size)`
   - Create `PdbHeader::new()`
   - Add table with `TableMetadata::new(name, bbox, row_count, row_length)`
     - Use v4 blob-table semantics: `row_length=1`, `row_count=byte_count`
   - Encode header with `PdbEncoder::encode_header()`
   - Encode table chunk with `PdbEncoder::encode_table(idx, chunk_data)`
   - Save PNG to `{base_path}/{table_name}.{tile_x}.{tile_y}.pdb.png`
2. Track all tiles in `TiledPdbHeader.tiles`

**Verification**:
- Write unit test: encode 16MB data into 2×2 4096×4096 tiles
- Verify each tile PNG exists and is valid
- Verify each tile decodes to correct byte chunk

**Output**: `TiledPdbEncoder::encode_table(name, data)` → saves N PNG files

## Phase 3: Multi-Tile Decoding

**Goal**: Reconstruct full table data from multiple tile frames.

**Steps**:
1. Load `TiledPdbHeader` from `{base_path}.tiles.json`
2. For each table in header:
   - Get all tiles from `header.tiles[table_name]`
   - Sort tiles by `byte_offset`
   - For each tile:
     - Load PNG via `PdbDecoder::load_png()`
     - Decode table via `PdbDecoder::decode_table(name)`
     - Concatenate to output buffer
3. Return full byte stream

**Verification**:
- Write unit test: round-trip 16MB data → tiles → decoded data
- Verify byte-identical with `diff`
- Verify VCC hash matches original

**Output**: `TiledPdbDecoder::decode_table(name)` → full `Vec<u8>`

## Phase 4: JSON Header Serialization

**Goal**: Save/load `TiledPdbHeader` to/from JSON.

**Steps**:
1. Add `#[derive(Serialize, Deserialize)]` to tiled structs
2. Implement `TiledPdbManager::save_header()`:
   - Serialize `self.header` to JSON
   - Write to `{base_path}.tiles.json`
3. Implement `TiledPdbManager::load_header()`:
   - Read JSON from `{base_path}.tiles.json`
   - Deserialize into `self.header`
   - Verify magic bytes and version

**Verification**:
- Write unit test: save + load header, verify equality
- Verify JSON is human-readable
- Verify version mismatch rejects

**Dependencies**: Add `serde` and `serde_json` to `Cargo.toml`

## Phase 5: Tiled Compiler/Extractor Examples

**Goal**: Create CLI tools for tiled PDB workflows.

**File**: `examples/compile_v4_1_tiled.rs`

**Steps**:
1. Parse CLI args:
   - `<output_base> <tile_size> <name> <file_path>`
   - Example: `/tmp/rootfs 4096 rootfs /path/to/rootfs.raw`
2. Calculate tile grid: `TileGridConfig::new(tile_size, file_size_pixels...)`
3. Create `TiledPdbEncoder`
4. Call `encode_table(name, file_data)`
5. Call `save_header()`

**File**: `examples/extract_v4_1_tiled.rs`

**Steps**:
1. Parse CLI args:
   - `<input_base> <table_name> <output_file>`
   - Example: `/tmp/rootfs rootfs /tmp/out.raw`
2. Create `TiledPdbDecoder`
3. Call `load_header()`
4. Call `decode_table(name)`
5. Write to output file

**Verification**:

- Verify round-trip byte-identical
